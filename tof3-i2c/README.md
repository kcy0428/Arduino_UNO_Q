# ToF 3 I²C Monitor — UNO Q / VL53L8CX

`tof-i2c`의 8×8 거리 맵을 센서 3개에 확장한 Arduino App입니다. 각 센서는
5 Hz로 측정하고, 웹 화면에서 별도의 히트맵·연결 상태·거리 통계·CSV 저장을 제공합니다.

## 배선

센서 1·2는 D20/D21(`Wire`)을 공유하고, **센서 3만 A4/A5(`Wire2`)의 별도
I²C 버스**를 씁니다 — UNO Q에는 I²C 버스가 하나가 아니라 여러 개 있고, 이
둘이 그중 헤더로 노출된 두 개입니다. 이렇게 나누면 한 버스에 물리는 센서가
3개에서 2개로 줄어 풀업 저항 부담이 줄고, 센서 3의 배선 문제가 센서 1·2에
전혀 영향을 주지 않습니다. 각 센서의 **LPn은 그래도 별도 핀**에 연결해야
합니다 — 같은 버스를 쓰는 센서끼리는 기본 I²C 주소 `0x29`가 겹치지 않게
하기 위함이고, 센서 3은 혼자 쓰는 버스라 주소가 겹칠 일은 없지만 코드는
동일하게 LPn으로 전원을 제어합니다.

| VL53L8CX 모듈 | UNO Q | 비고 |
| --- | --- | --- |
| 센서 1 LPn | D2 | |
| 센서 2 LPn | D3 | |
| 센서 3 LPn | D4 | |
| 센서 1·2 SDA | SDA / D20 (PB11) | `Wire`, 두 센서 공유 |
| 센서 1·2 SCL | SCL / D21 (PB10) | `Wire`, 두 센서 공유 |
| 센서 3 SDA | A4 | `Wire2`, 센서 3 전용 |
| 센서 3 SCL | A5 | `Wire2`, 센서 3 전용 |
| 세 센서 GND | GND | 공통 |
| 세 센서 SPI_I2C_N | GND (I²C 선택) | 공통 |
| 세 센서 VCC | **모듈** 사양에 맞는 전원 | 공통 |

전원을 끄고 배선을 변경하세요. 모듈의 LPn 입력이 UNO Q의 3.3V GPIO를
허용하는지 확인하세요. 칩 단품의 I/O에 3.3V를 직접 연결하면 안 됩니다.
PWREN 핀이 있는 캐리어는 제조사 회로에 맞게 활성화해야 합니다.
LPn 핀을 연결하지 않고 SDA/SCL만 공통 연결하면 같은 버스의 센서를 구분할
수 없습니다.

**풀업 저항**: VL53L8CX 브레이크아웃 보드는 보통 보드 자체에 풀업 저항이
있습니다. 한 버스에 센서를 2개 이상 물릴 때는 그중 하나의 풀업만 남기고
나머지는 제거하세요 — 여러 보드의 풀업이 병렬로 겹치면 버스가 규격보다
훨씬 세게 당겨져 통신이 간헐적으로 깨집니다(자세한 진단·측정 방법은
`tof3-i2c-notes.md` 참고).

앱은 부팅 시 LPn을 모두 LOW로 둔 후 하나씩 HIGH로 올려 주소를
`0x30`, `0x31`, `0x32`로 지정합니다(각각 센서 1·2·3).
주소는 7비트 표기이며, 드라이버 내부에서는 두 배인 주소를 사용합니다.
LPn으로 I²C를 격리하므로 센서 한 개가 오류를 내면 해당 센서만 3초 간격으로
다시 연결합니다. 정상 센서의 표시와 측정은 계속됩니다.

## 실행

Arduino App Lab의 앱 목록에서 **ToF 3 I2C Monitor**를 열고 Run을 누릅니다.
Web UI가 자동으로 열리지 않으면 `http://<보드-IP>:7000`을 브라우저에서 엽니다.
App Lab의 기본 Web UI는 시스템 브라우저에서 열립니다. 앱 목록에 없다면 보드
화면으로 돌아갔다가 다시 앱 목록을 열어 보세요.

명령으로 실행하면 현재 실행 중인 Arduino App이 중지됩니다.

```sh
arduino-app-cli app start /home/arduino/ArduinoApps/tof3-i2c
arduino-app-cli app logs /home/arduino/ArduinoApps/tof3-i2c --follow
```

센서 3개의 `실시간 측정` 표시와 증가하는 프레임 번호를 확인하세요.
`GET /api/status`는 세 센서의 상태·거리·프레임 시간을 `sensors` 배열로 제공합니다.
각 카드의 CSV는 해당 센서의 64개 영역을 원래 순서로 저장합니다.

오류가 보이면 각 센서의 LPn 핀, 공통 GND, SDA/SCL, 전원, SPI_I2C_N,
PWREN, I²C 풀업과 모듈의 전압 변환 회로를 확인하세요.
