tof3-i2c · Arduino UNO Q · VL53L8CX × 3

ToF 3 신호 경로

센서 세 개가 측정한 8×8 거리 맵이 I²C 버스, MCU 스케치, Router Bridge, Python 앱을 거쳐 웹 화면에 표시되는 과정입니다. sketch.ino, main.py, app.js의 실제 동작을 옮겼고, 거리 값은 예시 데이터입니다.

전체 데이터 흐름

점 하나가 메시지 하나입니다. 각 센서는 5 Hz로 측정하고, 브라우저는 응답을 받을 때마다 200 ms 뒤에 다시 요청합니다.

I²C 읽기 Bridge 프레임 Bridge 상태 HTTP 폴링

센서별 연결 상태

센서마다 독립된 상태 머신이 있습니다. 강조된 칸은 위 블록도에서 센서 2의 현재 상태입니다.

부팅 시 I²C 주소 지정

세 센서는 모두 기본 주소 0x29로 켜집니다. LPn 핀으로 한 번에 한 센서만 버스에 연결해 주소를 바꿉니다.
